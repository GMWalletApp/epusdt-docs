# 交易與交付

GMShop Edge 面向數位商品商城，由商城自身持有商品、結帳、庫存、權益與交付狀態。

## 商品與權益模型

專案支援組合使用：

- 永久、固定期限、限次、不限次、免費、一次購買與客戶主動續購等權益。
- 預置庫存商品，發放加密保存的卡密、帳號、啟用碼或憑證。
- 儲存在 R2 的私有下載商品，並透過 D1 授權記錄解析。
- 用於部署、腳本、資源開通或構建流程的自動化商品。

金額以最小貨幣單位的十進位整數字串保存，不使用浮點數計算。

## 上游供貨

GMShop Edge 可從以下來源同步上游商品：

- ACG `3.5.5` V4 Open API。
- 獨角數卡 Next `v1.3.1`。

供應商模組按 Provider 與 API 來源同步目錄，並在同一來源的可用等優先級帳號池中自動選擇採購帳號；上游返回內容仍透過統一交付記錄管線發放。

本地驗收測試可寫入冪等資料：

```bash
bun run seed:acceptance:local
# 同時寫入商品媒體、下載檔案和自動化制品
bun run seed:acceptance:local:r2
```

這些資料使用禁用的供應商帳號、`.example.invalid` 來源與關閉的自動同步，因此在你替換憑證並於管理後臺啟用帳號之前，不會請求真實上游。

## 結帳身份

註冊購買直接關聯 Better Auth 使用者。遊客訂單使用已驗證的結帳信箱，直到相同信箱的已驗證帳號認領。系統不建立影子帳號，也不維護獨立客戶表。

## 交付與營運

交付工作透過 D1、R2、Queues 與 Cron 處理，而不是依賴同步商城請求。這包含供應商採購與核驗、交付、通知、重試、保留與密鑰輪換流程。

管理後臺也覆蓋優惠券、退款、售後、營運保留與審計記錄。
