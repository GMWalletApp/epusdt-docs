# 商務與交付

GMShop Edge 在一個商城部署內統一管理商品、結帳、庫存、權益、供應商採購、交付和售後狀態。

## 商品與權益

支援三類商品：

- `stock`：原子分配加密預置文字，例如許可證金鑰、帳戶、啟用碼或憑證。
- `download`：授予對私有檔案的受限訪問權限。
- `automation`：執行部署、指令碼、資源供應或建置工作流，並支援 `none | optional | required` 產物策略。

權益可設定為永久、固定期限、限次、無限、免費、一次性或使用者續期。訂單會儲存不可變的輸入定義、定價、權益、交付和自動化快照。

## 使用者歸屬與餘額

註冊訂單直接引用 Better Auth 使用者。遊客訂單保留已驗證的結帳信箱，可由匹配的已驗證帳戶認領；系統不會建立影子使用者表。

每個帳戶均可使用商城餘額。帳本以最小貨幣單位的整數記錄變動，支援支付、退款和後台調整，不使用浮點數計算金額。

## 供應商來源

GMShop Edge 支援：

- ACG `3.5.5` V4 Open API。
- Dujiao Next `v1.3.1`。
- 原生 GMShop Edge 例項間供應商整合。

原生供應商 API 使用管理員建立的 API Key、經過身分驗證的 HTTP 介面、商品目錄存取和冪等訂單操作。另一套 GMShop Edge 可以使用內建供應商介面卡同步商品並透過該 API 完成交付。

每個服務商/API 來源的可用帳戶組成等優先順序池。目錄同步、採購、回呼/對帳和交付均經過持久狀態機及統一交付記錄管線。

## 交付與營運

佇列和定時任務處理庫存分配、供應商採購、私有下載交付、自動化任務、通知、退款、重試、過期、取消、保留策略和人工恢復。客戶端輸入不能選擇私有物件鍵。

本地驗收資料：

```bash
bun run seed:local
```

該命令僅可在本地執行且具有冪等性。它建立使用 `.example.invalid` 地址的停用供應商帳戶；替換憑證並明確啟用帳戶前，不會存取真實上游。
