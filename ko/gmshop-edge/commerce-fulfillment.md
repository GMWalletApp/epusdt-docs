# 판매 및 주문 이행 {#commerce-and-fulfillment}

GMShop Edge는 단일 쇼핑몰 환경에서 카탈로그 관리, 결제, 재고 관리, 권한 관리, 공급업체 구매, 주문 처리 및 사후 관리 기능을 제공합니다.

## 제품 및 권한 {#products-and-entitlements}

상품 유형은 다음과 같습니다.

- `stock`: 암호화된 미리 설정된 텍스트(예: 라이선스 키, 계정, 활성화 코드, 또는 인증 정보)를 원자적으로 할당합니다.
- `download`: 비공개 파일에 제한된 접근 권한을 부여합니다.
- `automation`: 배포, 스크립트, 리소스 프로비저닝 또는 빌드 워크플로를 실행합니다. 결과물 정책은 `none | optional | required` 중 하나를 사용합니다.

다음과 같은 권한이 적용될 수 있습니다: 영구적, 특정 기간, 제한적, 무제한적, 무료, 일회성, 또는 고객 재신청. 주문은 불변의 입력 정의, 가격, 권한, 이행 및 자동화의 스냅샷을 유지합니다.

## 고객 소유 및 지갑 {#customer-ownership-and-wallet}

등록된 주문은 Better Auth 사용자를 직접 참조합니다. 게스트 주문은 확인된 결제 이메일을 유지하며, 일치하는 확인된 계정으로 주장할 수 있습니다. 따라서, "그림자 고객" 테이블은 생성되지 않습니다.

각 계정은 스토어의 지갑을 사용할 수 있습니다. 회계 장부는 소수 단위의 정수 움직임을 기록하며, 부동 소수점 없이 결제, 환불, 그리고 관리 조정 기능을 지원합니다.

## 공급업체 상품 조달 {#supplier-sourcing}

GMShop Edge는 다음을 지원합니다.

- ACG `3.5.5` V4 오픈 API
- 두자요 다음 `v1.3.1`
- 원래 GMShop Edge 공급업체 간의 통합.

본래 공급업체 API는 관리자가 생성한 API 키를 사용하며, 인증된 HTTP 엔드포인트, 카탈로그 접근 권한, 그리고 중복 없는 주문 기능을 제공합니다. 또 다른 GMShop Edge 인스턴스는 자체 내장된 공급업체 어댑터를 사용하여 제품을 동기화하고, 이 API를 통해 주문을 처리할 수 있습니다.

각 제공업/API 소스에 대해, 자격 있는 계정들은 동일 우선순위 풀을 형성합니다. 카탈로그 동기화, 구매, 피드백/조정, 그리고 배송은 내구성 있는 상태 머신과 통합 배송 기록 파이프라인을 통해 이루어집니다.

## 실현 및 운영 {#fulfillment-and-operations}

대기열 및 예약된 작업은 재고 배분, 공급업체 구매, 비공개 다운로드 배송, 자동화 작업, 알림, 환불, 재시도, 만료, 취소, 유지 및 수동 복구를 처리합니다. 클라이언트 입력으로 절대 선택되지 않는 개인 객체 키를 사용합니다.

로컬 인수 테스트용 데이터 설정

```bash
bun run seed:local
```

이 명령어는 로컬에서만 작동하며, 중복 실행해도 동일한 결과를 생성합니다. `.example.invalid`의 출처를 가진 비활성화된 공급업체 계정을 생성하며, 자격 증명이 변경되고 계정이 명시적으로 활성화될 때까지 실제 업스트림과의 연결을 시도하지 않습니다.
