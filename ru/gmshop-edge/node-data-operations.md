# Управление данными в Bun {#bun-data-operations}

Среда выполнения Bun сохраняет свою авторитетную базу данных SQLite в файле `$GMSHOP_DATA_DIR/gmshop.sqlite` и приватные объекты в том же каталоге данных. Используйте поддерживаемую команду `bun run data -- …` вместо копирования существующего файла SQLite.

## Резервное копирование и восстановление {#backup-and-restore}

Остановите контейнер перед созданием резервной копии или восстановлением, чтобы база данных, приватные объекты и состояние долговечной очереди оставались в одном логическом моменте времени.

```bash
GMSHOP_DATA_DIR=/srv/gmshop bun run data -- backup \
  --output /srv/backups/gmshop-2026-08-21

GMSHOP_DATA_DIR=/srv/gmshop-restored bun run data -- restore \
  --input /srv/backups/gmshop-2026-08-21
```

Сохраняйте резервную копию вне каталога данных. Восстановление допускается только в новый или пустой каталог. Существующий экземпляр не перезаписывается. Каждый файл сверяется с манифестом. При восстановлении также проверяются целостность SQLite, внешние ключи и контрольные суммы неизменяемых миграций.

Опубликованное изображение включает в себя тот же CLI:

```bash
docker compose stop gmshop-edge
docker compose run --rm --no-deps \
  --volume "$PWD/backups:/backups" \
  gmshop-edge bun run data -- backup --output /backups/gmshop-2026-08-21
```

Резервные копии содержат учетные данные, информацию о клиентах, заказы, предустановленные остатки, приватные загрузки и артефакты автоматизации. Шифруйте их при хранении, ограничьте доступ и регулярно проверяйте возможность восстановления.

CLI использует `$GMSHOP_DATA_DIR/.maintenance.lock`. Если программа завершится аварийно и оставит файл блокировки, сначала убедитесь, что ни один серверный или командный файл не использует эту директорию, а затем удалите только устаревший файл блокировки.

## Импортировать экспорт Cloudflare {#import-a-cloudflare-export}

Экспортируйте объекты D1 как SQL и R2 в локальную директорию, путь которой соответствует исходным ключам. Импортируйте только в новую или пустую директорию Bun.

```bash
wrangler d1 export DB --remote --output ./d1-export.sql
GMSHOP_DATA_DIR=/srv/gmshop bun run data -- import-cloudflare \
  --d1-sql ./d1-export.sql \
  --r2-dir ./r2-export \
  --r2-manifest ./r2-metadata.json
```

`--r2-dir` является необязательным параметром, когда у экземпляра нет объектов. `--r2-manifest` также является необязательным параметром, но требует `--r2-dir`; он сохраняет HTTP-данные R2 и пользовательские метаданные.

Импортер проверяет миграции репозитория, целостность SQLite и внешние ключи, а затем конвертирует ключи R2 в приватный формат с хэшированными объектами. Он отклоняет небезопасные пути, неизвестные метаданные, метаданные без объекта и непустые цели. Отсутствует режим перезаписи и двунаправленная синхронизация.
