# Архитектура {#architecture}

GMShop Edge использует ту же технологию React/TanStack «полный стек» на Cloudflare Workers или Bun/Nitro. Один развертывание охватывает публичный магазин, область учетных записей клиентов, процесс оформления заказа, обработку заказов, интеграцию с поставщиками, интеграцию с Telegram и административную панель.

## Общие границы приложения {#shared-application-boundaries}

Маршруты остаются узкими. Функциональные страницы, схемы, серверные функции и поведение доменов находятся в директории `src/features`; компоненты для работы между доменами находятся в `src/server`; схемы Drizzle находятся в `src/db/schema`.

Приложение сохраняет информацию об идентификации, RBAC, каталоге, заказах, инвентаризации, правах доступа, состоянии поставщиков, записи кошелька, уведомления, защиту от повторного воспроизведения, ограничения скорости, "outbox" и данные аудита в основной базе данных. Деньги хранятся в виде строковых десятичных целых чисел в минимальных единицах и никогда не вычисляются с использованием чисел с плавающей точкой.

## Адаптеры Cloudflare Workers {#cloudflare-workers-adapters}

Использование распределения рабочих:

- `DB`: D1 для использования в официальных приложениях и коммерческих целях.
- `FILES` — закрытое хранилище R2 для медиафайлов товаров, загрузок, результатов автоматизации и экспортированных данных.
- `CACHE`: для проверенных, версированных, ограниченных кэшей чтения; ограничения безопасности остаются определяющими для базы данных.
- `COMMERCE_QUEUE`: Очередь для задач, связанных с доставкой, автоматизацией, уведомлениями, поставщиками и возвратами, с "мертвой" (или "остаточной") очередью.
- `EMAIL` — необязательная привязка Cloudflare Send Email.
- Одноминутные триггеры Cron для запланированной обработки и обслуживания.

## Адаптеры Bun/Nitro {#bun-nitro-adapters}

Среда выполнения Bun предоставляет эквивалентные адаптеры в одном каталоге данных:

- Основная база данных — SQLite.
- Кэш с ограниченным объемом, находящийся в процессе.
- Частное локальное хранилище.
- Прочная очередь, основанная на SQLite.
- Одноминутный планировщик в процессе.

`GMSHOP_DATA_DIR` содержит базу данных, объекты, состояние очереди и данные выполнения. Bun намеренно является **одноэкземплярным**: развертывание с несколькими репликами и использование общего сетевого хранилища не поддерживаются.

## Данные и фоновые задачи {#data-and-background-work}

Приватные объекты решаются на основе авторизованных записей в базе данных; клиенты никогда не выбирают ключи объектов. Очереди и запланированные задачи обрабатывают синхронизацию с поставщиками, закупки, выполнение заказов, уведомления, возвраты, повторные попытки, хранение, обслуживание Telegram и ротацию ключей вне запросов синхронного магазина.

Базовая точка миграции для чистой установки – `drizzle/0000_gmshop.sql`; последующие миграции применяются последовательно, а их контрольные суммы проверяются операциями данных Bun.
