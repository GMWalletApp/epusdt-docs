# Продажи и выполнение заказов {#commerce-and-fulfillment}

GMShop Edge объединяет в одном решении каталог, процесс оформления заказа, управление запасами, систему предоставления прав, закупки у поставщиков, обработку заказов и послепродажное обслуживание.

## Продукты и права {#products-and-entitlements}

Доступные типы товаров:

- `stock`: атомарно выделяет зашифрованный стандартный текст, например, ключи лицензий, учетные записи, коды активации или учетные данные.
- `download` — предоставляет ограниченный доступ к закрытым файлам.
- `automation` выполняет развёртывание, скрипты, выделение ресурсов или процессы сборки с политикой для артефактов `none | optional | required`.

Права могут быть постоянными, на определенный срок, ограниченными, неограниченными, бесплатными, разовыми или возобновляемыми клиентом. Заказы сохраняют неизменные данные, определяющие параметры, цены, права, выполнение и автоматизацию.

## Право собственности клиента и цифровой кошелёк. {#customer-ownership-and-wallet}

Зарегистрированные заказы напрямую связываются с пользователями Better Auth. Заказы от гостей сохраняют подтвержденный адрес электронной почты для оформления заказа и могут быть оформлены с помощью соответствующего подтвержденного аккаунта; не создается таблица "теневых" клиентов.

Каждый счет может использовать кошелек магазина. Бухгалтерный учет фиксирует точные, целочисленные изменения на минимальной единице, а также поддерживает операции оплаты, возврата и административные корректировки без использования чисел с плавающей точкой.

## Закупка у поставщиков {#supplier-sourcing}

GMShop Edge поддерживает:

- ACG `3.5.5` V4 Open API.
- Dujiao Next `v1.3.1`
- Интеграция GMShop Edge между поставщиками.

Родной API поставщика использует API-ключи, созданные администратором, аутентифицированные HTTP-концы, доступ к каталогу и атомарные операции заказа. Другой экземпляр GMShop Edge может использовать встроенный адаптер поставщика для синхронизации продуктов и выполнения заказов через этот API.

Для каждого источника поставщика/API, счета, соответствующие критериям, образуют равный приоритетный пул. Синхронизация каталога, закупки, обратная связь/согласование, и доставка проходят через надежные состояния и единую систему обработки данных о доставке.

## Выполнение и деятельность {#fulfillment-and-operations}

Очереди и запланированные задачи обрабатывают распределение запасов, закупки у поставщиков, доставку приватных файлов, автоматизированные задачи, уведомления, возвраты, повторные попытки, срок действия, отмену, сохранение и ручное восстановление. Ключи объектов для приватного использования никогда не выбираются через ввод пользователя.

Для локальных приёмочных тестов

```bash
bun run seed:local
```

Команда работает только локально и является идентичной (idempotной). Она создает отключенные учетные записи поставщиков с доменами `.example.invalid` и не может взаимодействовать с реальными серверами, пока не будут заменены учетные данные и учетные записи явно не будут включены.
