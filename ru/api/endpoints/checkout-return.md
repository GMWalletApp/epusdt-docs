# Вернуться на сайт продавца {#return-to-the-merchant}

<ApiRoute />

<a class="api-example-jump" href="#request-example">Пример запроса ↓</a>

Для оплаченного заказа EPay шлюз возвращает покупателя на сайт продавца с подписанными параметрами. В остальных случаях покупатель возвращается на страницу оплаты. Выполняйте заказ после проверки подписи асинхронного уведомления.

## Параметры {#parameters}

`trade_id` · `string` · PATH

Идентификатор транзакции EPUSDT, полученный при создании заказа.
