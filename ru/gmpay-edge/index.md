# GMPay Edge {#gmpay-edge}

[GMPay Edge](https://github.com/GMWalletApp/gmpay-edge) — криптовалютный платёжный шлюз для одного владельца, который можно самостоятельно развернуть на **Cloudflare Workers или в Docker с Bun/Nitro**.

Это отдельный проект, отличный от Epusdt. Используйте Epusdt, когда вам нужна документация Go-шлюза, предоставленная этим сайтом; оцените GMPay Edge, если вы хотите развернуть TypeScript-шлюз как в Cloudflare Workers, так и в виде Docker-контейнера с локальным хранением на базе SQLite.

> GMPay Edge находится в активной разработке. Встроенные интеграции означают, что функциональность уже присутствует в проекте; однако для использования в производственной среде требуются конечные точки, принадлежащие владельцу, или только для чтения учетные данные, настроенные методы получения, резервные копии, мониторинг и реальные тесты соответствия платформе.

## Возможности {#what-it-provides}

- Подписаны API для торговлей GMPay с использованием JSON и формы ввода.
- Совместимость EPay на уровне API без необходимости поддерживать отдельную модель заказа.
- Адаптивный процесс оформления заказа, панель администратора, страницы статуса для публичного использования, и документация OpenAPI в реальном времени.
- Надежная доставка Webhook через очередь с механизмом "outbox", с историей повторных попыток, возможностью ручного повтора и записями аудита.
- Сканирование платежей, проверка сроков действия, очистка, оценка состояния соединения и синхронизация скорости с помощью специализированных, долговечных очередей и планировщиков, адаптированных для выполнения в реальном времени.
- Улучшенная аутентификация, TOTP и динамическая многоролевая RBAC для административного управления.
- Автоматизация Telegram-ботов с помощью grammY, включая inline-заказы, публичные команды и подписки на уведомления.
- Интерфейс на шести языках.
