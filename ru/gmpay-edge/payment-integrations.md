# Интеграция платёжных сервисов {#payment-integrations}

GMPay Edge включает адаптеры для работы с блокчейном, биржами и кошельками. Уровень раскрытия информации контролируется отдельно с помощью настроенных методов получения.

Метод должен иметь необходимую публичную связь или конфигурацию только для чтения, а также успешно проходить проверки доступности, прежде чем он может быть предложен платящему лицу.

| Тип | Интеграция | Встроенные активы |
| --- | --- | --- |
| В блокчейне | TRON / TRC20 | USDT, TRX |
| В блокчейне | Ethereum / ERC20 | USDT, USDC, ETH |
| В блокчейне | Base | USDT, USDC, ETH |
| В блокчейне | BNB Smart Chain / BEP20 | USDT, USDC, BNB |
| В блокчейне | Polygon | USDT, USDC, MATIC |
| В блокчейне | TON | USDT, GRAM |
| В блокчейне | Aptos | USDT, USDC |
| В блокчейне | Solana | USDT, USDC |
| Биржа | Binance | USDT, USDC |
| Биржа | OKX | USDT, USDC |
| Кошелёк | OKPay | USDT, TRX |

Встроенные интеграции означают, что эта функциональность уже присутствует в проекте. Однако, для использования в производственной среде все еще требуются конечные точки, принадлежащие пользователю, или учетные данные только для чтения, настроенные методы приема, резервные копии, мониторинг и реальные тесты приемки на платформе.
