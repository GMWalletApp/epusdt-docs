# FAQ {#faq}

## Какой маршрут мне следует выбрать? {#which-route-should-i-use}

- Для всех новых интеграций **используйте GMPay**.
- **Используйте перенаправление, совместимое с EPay**, только если внешняя система ожидает переход на кассу в формате EPay.
- Маршрут `/payments/epusdt/v1/order/create-transaction` больше не зарегистрирован в текущей версии. **Не используйте его для новых интеграций.**

## Откуда берутся ключи `pid` и подписи? {#where-do-pid-and-signing-keys-come-from}

Из записей API-ключей в панели администратора. У каждого продавца есть `pid` и соответствующий `secret_key`.

## Почему конфигурация GMPay отличается между различными средами? {#why-does-the-gmpay-config-differ-between-environments}

Поскольку `GET /payments/gmpay/v1/config` рассчитывается на основе ваших собственных административных данных.

Список `data.supported_assets` зависит от активных цепочек, активных токенов цепочек и доступных адресов кошельков в данной среде.

## Какие узлы мне нужны? {#which-nodes-do-i-need}

Встроенный ChainScanner включает публичные узлы. Для TRON можно использовать поддерживаемую публичную точку доступа без ключа TronGrid. При добавлении узла выберите сеть и протокол, который действительно обслуживает провайдер. Подписка WebSocket может сообщить о новом блоке, а отдельный HTTP-узел — вернуть его содержимое.

Панель управления отображает прогресс сканирования и предупреждает, когда наблюдаемое отставание превышает пять минут. Для частых запросов к Solana, TON или Plasma, настройте резервные узлы от двух независимых провайдеров и проверьте их лимиты.

## Как устанавливаются обменные курсы? {#how-are-exchange-rates-set}

Выберите `fixed` для применения `rate.forced_rate_list` или `auto` для загрузки курсов из `rate.api_url`. Если обновление не удалось, автоматический режим сохраняет последние кешированные курсы. Пустой список фиксированных курсов восстанавливает встроенные курсы CNY для USDT и USDC.
