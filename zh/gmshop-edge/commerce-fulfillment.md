# 商业与交付

GMShop Edge 在一个商城部署内统一管理商品、结账、库存、权益、供应商采购、交付和售后状态。

## 商品与权益

支持三类商品：

- `stock`：原子分配加密预置文本，例如许可证密钥、账户、激活码或凭据。
- `download`：授予对私有文件的受限访问权限。
- `automation`：执行部署、脚本、资源供应或构建工作流，并支持 `none | optional | required` 产物策略。

权益可配置为永久、固定期限、限次、无限、免费、一次性或用户续期。订单会保存不可变的输入定义、定价、权益、交付和自动化快照。

## 用户归属与余额

注册订单直接引用 Better Auth 用户。游客订单保留已验证的结账邮箱，可由匹配的已验证账户认领；系统不会创建影子用户表。

每个账户均可使用商城余额。账本以最小货币单位的整数记录变动，支持支付、退款和后台调整，不使用浮点数计算金额。

## 供应商来源

GMShop Edge 支持：

- ACG `3.5.5` V4 Open API。
- Dujiao Next `v1.3.1`。
- 原生 GMShop Edge 实例间供应商集成。

原生供应商 API 使用管理员创建的 API Key、经过身份验证的 HTTP 接口、商品目录访问和幂等订单操作。另一套 GMShop Edge 可以使用内置供应商适配器同步商品并通过该 API 完成交付。

每个服务商/API 来源的可用账户组成等优先级池。目录同步、采购、回调/对账和交付均经过持久状态机及统一交付记录管线。

## 交付与运营

队列和定时任务处理库存分配、供应商采购、私有下载交付、自动化任务、通知、退款、重试、过期、取消、保留策略和人工恢复。客户端输入不能选择私有对象键。

本地验收数据：

```bash
bun run seed:local
```

该命令仅可在本地运行且具有幂等性。它创建使用 `.example.invalid` 地址的禁用供应商账户；替换凭据并明确启用账户前，不会访问真实上游。
