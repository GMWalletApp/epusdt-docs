# 交易与交付

GMShop Edge 面向数字商品商城，由商城自身持有商品、结账、库存、权益与交付状态。

## 商品与权益模型

项目支持组合使用：

- 永久、固定期限、限次、不限次、免费、一次购买与客户主动续购等权益。
- 预置库存商品，发放加密保存的卡密、账号、启用码或凭证。
- 储存在 R2 的私有下载商品，并通过 D1 授权记录解析。
- 用于部署、脚本、资源开通或构建流程的自动化商品。

金额以最小货币单位的十进位整数字串保存，不使用浮点数计算。

## 上游供货

GMShop Edge 可从以下来源同步上游商品：

- ACG `3.5.5` V4 Open API。
- 独角数卡 Next `v1.3.1`。

供应商模组按 Provider 与 API 来源同步目录，并在同一来源的可用等优先级账号池中自动选择采购账号；上游返回内容仍通过统一交付记录管线发放。

本地验收测试可写入幂等数据：

```bash
bun run seed:acceptance:local
# 同时写入商品媒体、下载文件和自动化制品
bun run seed:acceptance:local:r2
```

这些数据使用禁用的供应商账号、`.example.invalid` 来源与关闭的自动同步，因此在你替换凭证并于管理后台启用账号之前，不会请求真实上游。

## 结账身份

注册购买直接关联 Better Auth 用户。游客订单使用已验证的结账信箱，直到相同信箱的已验证账号认领。系统不建立影子账号，也不维护独立客户表。

## 交付与运营

交付工作通过 D1、R2、Queues 与 Cron 处理，而不是依赖同步商城请求。这包含供应商采购与核验、交付、通知、重试、保留与密钥轮换流程。

管理后台也覆盖优惠券、退款、售后、运营保留与审计记录。
